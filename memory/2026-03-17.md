# 2026-03-17 — RSS → 选题评分 → 自动出稿 → 推公众号草稿箱（主流程）

## 目标
- **每天 23:00** 抓取 RSS + 生成选题清单并评分，选 Top。
- **每天 07:00** 基于 Top 选题自动出稿，并推送到微信公众号**草稿箱**。
- 当前阶段：**科技科普方向优先**（稳定后再扩商业观察）。

## RSS 源验证
- RSSHub 源可用：`https://rss.lambda.xin/36kr/information/technology`
- 关键注意：`blogwatcher add` 必须显式指定 `--feed-url`，否则 scan 会提示 “No feed or scraper configured”。

## 数据与脚本（workspace）
- RSS 数据落地目录：`workspace/rss/`
  - `rss/36kr-tech.json`（当日 new items 列表）
  - `rss/36kr-tech-brief.json`（Top + Top10 + 给 HUGO 的 brief）
- 脚本：
  - `scripts/rss_radar_fetch.py`：解析 `blogwatcher articles --all --blog <name>` 输出为结构化 JSON
  - `scripts/rss_radar_select_and_brief.py`：对候选标题做启发式评分（AI/算力/Agent 关键词优先），输出 brief
  - `scripts/rss_nightly.sh`：夜间任务：scan + 生成 json/brief，并打印 Top/URL/Top3
  - `scripts/rss_morning_to_drafts.sh`：早晨任务：
    1) 读取 brief 的 Top1
    2) 调用 HUGO 生成文章（md）
    3) 调用 DALI 生成封面图（强制“无文字/无UI/无路牌”）并用 ffmpeg 裁剪为 1080×864
    4) 通过 wechat-publisher（wenyan）推送到公众号草稿箱

## 定时任务（OpenClaw cron）
- `RSS nightly scan + topic ranking`：23:00（Asia/Shanghai）→ 把 Top/URL/Top3 发到当前 Telegram 私聊（5966032490）
- `RSS morning: draft to WeChat`：07:00（Asia/Shanghai）→ 自动出稿并推草稿箱；成功/失败摘要发到当前 Telegram 私聊

## 运行约束（为稳定性固化）
- **严禁泄露任何密钥**（脚本与通知消息都不回显 env）。
- **封面图/配图一律禁止出现文字**（grok-imagine 容易生成伪文字/汉字）。prompt 与 negative 强制 no text/no signage/no UI。

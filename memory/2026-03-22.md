## CPA Codex OAuth 远程编排：对外使用约定沉淀
- 对外域名：`https://cpa.lambda.xin`
- 管理接口鉴权：服务端使用环境变量 `MANAGEMENT_PASSWORD`；调用端可自定义变量名（示例用 `MGMT_KEY` 仅为客户端环境变量名，不是系统内置）。
- 调用时 header 二选一：`X-Management-Key: <key>` 或 `Authorization: Bearer <key>`。
- 推荐接口（语义化别名）：
  - `GET /v0/management/oauth/codex/start` → 返回 `url/state/provider/created_at/expires_at`（TTL=30min）
  - `POST /v0/management/oauth/codex/complete` → 支持提交 `redirect_url`（完整 callback）或 `code+state`
  - `GET /v0/management/oauth/sessions/status?state=...` → `wait|error|ok`（`ok` 表示会话不存在或已完成并清理；是否成功需看 auth 落盘/管理后台）
- “全自动注册+登录+token”不做（风险/风控/验证码）；可做到“除人工浏览器登录外其余自动”。
